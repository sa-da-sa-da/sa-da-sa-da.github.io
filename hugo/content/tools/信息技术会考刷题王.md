# 信息技术会考刷题王

面向高中信息技术学业水平考试（会考）的题库刷题工具。内置 **1078 道**真题与模拟题，题型覆盖单选题、多选题、判断题、填空题、综合分析、Python 代码选择与 WPS 表格操作。支持极速连刷、键盘操作、连击积分、错题本与收藏夹，全程在浏览器本地运行，记录自动保存，刷新不丢。

## 直接访问

- 点击 [信息技术会考刷题王](https://www.sakaay.com/lab/AI/xxhk.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/xxhk.html 并访问

> **提示**：题库已内置在页面中，首次打开无需联网下载即可使用；答题进度、错题、收藏均保存在浏览器本地（localStorage），清理浏览器数据会清空记录。

## 核心功能

- **七大题型全覆盖**：单选 / 多选 / 判断 / 填空 / 综合分析 / Python 代码选择 / WPS 表格，题库总量 1078 题
- **极速刷题模式**：键盘操作、答对自动跳下一题，连击（Combo）与积分系统让刷题更有动力
- **错题本**：自动收集答错的题目，支持「只重做错题」与一键导出，针对性查漏补缺
- **收藏夹**：标记重点难题随时回看
- **逐题回顾**：作答结束后可逐题复盘，对照解析加深理解
- **进度留存**：学习记录、积分、错题、收藏自动保存在本地，关闭页面不丢失
