# 本地文档工具箱

纯浏览器端的文档处理小工具箱，包含「文件转 PDF」与「PDF 提取指定页面」两项功能。所有转换均在本地完成，文件不上传服务器，适合处理含隐私的班级材料、学生档案等。

## 直接访问

- 点击 [本地文档工具箱](https://www.sakaay.com/lab/AI/pdf.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/pdf.html 并访问

> **提示**：转换全程在本机浏览器执行，文件不会上传网络。转 PDF 由浏览器打印引擎导出——点击按钮后弹出打印窗口，请在「目标打印机」处选择 **「另存为 PDF / 保存为 PDF」**，中文不乱码且自动分页。受浏览器能力限制，仅支持 `.docx` / `.html` 转 PDF，不支持老版 `.doc`/`.xls`/`.ppt`（老 `.doc` 请先用 LibreOffice 另存为 `.docx`）；加密或受密码保护的 PDF 无法解析拆分。

## 核心功能

- **文件转 PDF**：上传 `.docx` 或 `.html` 文件，通过浏览器打印引擎导出为 PDF（选「另存为 PDF」），中文不乱码、自动分页
- **PDF 提取页面**：上传 PDF，按页码范围（如 `1-3,5`）提取指定页，生成新的 PDF
- **纯本地处理**：不依赖服务器，文件不离开浏览器，保护隐私
- **即开即用**：界面简洁，选择文件 → 点击生成 → 在打印窗口另存为 PDF
