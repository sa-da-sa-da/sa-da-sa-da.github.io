# 河南省高二信息技术会考复习策略

> 覆盖必修一「数据与计算」+ 必修二「信息系统与社会」全部考点
>
> 满分 100 分 ｜ 机考 · 约 45 分钟 ｜ 合格等级 A/B/C/D

---

## 01 考试概览

河南省普通高中信息技术学业水平合格性考试，依据《普通高中信息技术课程标准（2017年版2020年修订）》实施，考查范围为两个必修模块的全部内容[^1][^2]。2024级学生的考试安排在 2026 年 1 月 8 日至 9 日上午进行，即高二年级上学期期末[^3]。按此规律，2025级（即 2026 年秋季入学高二的）学生考试时间预计在 2027 年 1 月中旬。

| 项目 | 说明 |
| --- | --- |
| 考试科目 | 信息技术（普通高中 10 个学业水平考试科目之一） |
| 考查范围 | 必修一「数据与计算」+ 必修二「信息系统与社会」全部内容 |
| 考试形式 | 无纸化机考，上机操作 |
| 考试时长 | 约 45 分钟 |
| 卷面满分 | 100 分（主卷） |
| 成绩呈现 | 等级制：A（优秀）、B（良好）、C（及格）、D（不及格） |
| 合格标准 | 达到 C 等级及以上为合格 |

会考性质为合格性考试，不是选拔性考试，整体难度以基础与中等题为主，重点考查对核心概念的识记理解和基本操作技能。只要认真复习，绝大部分同学都能顺利通过。但近年来命题越来越灵活，大量题目被包装在真实情境中（如智慧教育平台、无人超市、家庭网络组建等），仅靠死记硬背容易丢分。

---

## 02 题型与分值分布

根据 2025 年河南省真题分析，试卷由四类题型构成，选择题占分最高，操作处理题紧随其后[^4][^5]。

> 图1：试卷各题型分值分布

| 题型 | 题量 | 分值 | 考查重点 |
| --- | --- | --- | --- |
| 选择题 | 20题 | 40分 | Python 基础、信息编码、音频数据量计算、大数据特征、人工智能应用判断、网络基础等概念辨析 |
| 判断题 | 5题 | 10分 | 数据与信息的关系、内存特性、人工智能发展阶段、办公软件功能等易混点 |
| 综合应用题 | 2题 | 20分 | 家庭网络配置、信息系统开发流程、路由器设置等情境综合分析（含填空、判断、单选、多选） |
| 操作处理题 | 2题 | 30分 | Python 编程（约15分，阅读/修改/补全程序）+ Excel/WPS 数据处理（约15分，函数、公式、图表） |

> 选择题和操作题合计占 70 分，是拉开分差的主战场。选择题覆盖面广，要求每个知识点都有印象；操作题要求真正动手写过 Python 代码、操作过 WPS/Excel，纸上谈兵远远不够。

## 03 模块一：数据与计算核心考点

本模块对应必修一，涵盖数据与信息、知识与数字化学习、算法基础、程序设计基础、数据处理与可视化、人工智能六大主题。选择题和编程操作题的大部分内容出自这一模块。

> 图2：模块一各章考点重要程度评估

### 第一章 数据与信息

#### 数据编码与进制转换

计算机内部以二进制处理所有信息，理解进制转换是本章核心。需要掌握二进制、十进制、十六进制之间的互相转换。**除基取余法**用于十进制转 R 进制（不断除以 R，余数逆序排列）；**按权展开求和法**用于 R 进制转十进制（各位数字乘以对应权值后相加）。十六进制中 A–F 分别代表 10–15。

```text
十进制 → 二进制：不断除以 2，余数逆序排列
二进制 → 十进制：1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11
```

#### 字符编码

标准 ASCII 码是单字节编码系统，共 128 种编码（0–127），每个 ASCII 字符占 1 个字节。汉字编码中，GB2312 每个汉字占 2 个字节。需要区分输入码（外码，用于输入）、机内码（内码，用于存储）、输出码（字型码，用于显示）三种编码方式。条形码和二维码也属于信息编码，二维码的信息存储量和功能远大于条形码。

#### 模拟信号与数字信号

模拟信号是连续变化的信号，数字信号是离散的信号。音频数字化需要经过**采样、量化、编码**三个步骤。音频数据量计算公式是高频考点：

```text
数据量（字节）= (采样频率 × 量化位数 × 声道数) ÷ 8 × 持续时间（秒）
```

例如：44.1kHz 采样频率、16 位量化位数、双声道、30 秒音频，数据量 = (44100 × 16 × 2) ÷ 8 × 30 = 5,292,000 字节 ≈ 5.04MB。

> **易错点**
>
> 很多同学记不住公式中"÷ 8"的含义——采样位数是比特（bit），而数据量单位是字节（Byte），1 字节 = 8 比特，所以要除以 8 进行单位换算。做题时先确认单位，再代入计算。

#### 大数据特征

大数据的"4V"特征包括：数据量大（Volume）、处理速度快（Velocity）、数据类型多样（Variety）、**价值密度低**（Value）h。"价值密度高"是常见的错误选项——大数据虽然总量庞大，但单条数据的价值密度低，需要通过海量数据的综合分析才能挖掘出价值。

### 第二章 知识与数字化学习

信息是数据经过加工处理后形成的具有意义的内容。对同样的数据，不同的人可能获得不同的信息，因为信息的获取与接收者的知识背景、经验和关注点有关。知识是人类在认识与改造世界的实践中获得的经验的结晶，智慧则是运用知识解决实际问题的能力。这一章在判断题中出现频率较高。

#### 数据采集工具

常见的数据采集方式包括：传感器采集（如智能锁采集人脸/指纹）、网络爬虫（采集网页数据）、摄像头/摄像机采集（图像视频）、文献检索工具（采集已有文献资料）。判断题常考哪些属于、哪些不属于采集工具。

### 第三章 算法基础

#### 算法的定义与特征

算法是有限步骤内求解某一问题的一组明确规则。五大特征：**有穷性**（步骤有限，不能无限循环）、**确定性**（每一步含义唯一）、**可行性**（每一步可通过计算机实现）、**零个或多个输入**、**至少一个输出**。判断题常把"有零个或多个输入"改成"必须有一个或多个输入"来设陷阱。

#### 算法的三种基本控制结构

任何复杂算法都可由**顺序结构**、**选择结构**（根据条件判断做选择）和**循环结构**组合构成。循环结构分两种：当型循环（While，先判断条件再执行循环体）和直到型循环（Until/Do-While，先执行循环体再判断条件）。

#### 枚举算法

枚举算法是高频考点。其核心思想是逐一列举所有可能的情况，逐一判断是否符合条件。典型例子：求所有能被 15 和 25 整除的三位数。判断一道题能否用枚举算法求解的关键在于：答案范围是否有限且可逐一列举、是否有明确的判断条件。

#### 程序设计的一般流程

正确顺序为：**分析问题 → 设计算法 → 编写程序 → 调试运行**。选择题常打乱顺序设干扰项。

### 第四章 程序设计基础（Python）

Python 是本模块的重中之重，选择题和操作题都大量涉及。以下知识点需逐一掌握。

#### 数据类型

| 类型 | 关键字 | 说明 | 示例 |
| --- | --- | --- | --- |
| 整型 | int | 整数 | 5, -3, 0 |
| 浮点型 | float | 小数 | 3.14, -0.5 |
| 字符串型 | str | 用引号括起 | "hello", 'abc' |
| 布尔型 | bool | True / False | True, False |

Python 源代码文件的扩展名是 `.py`，这是选择题第一题级别的送分题。

#### 运算符与表达式

算术运算符优先级从高到低：**幂运算（\*\*）** → **乘（\*）、除（/）、整除（//）、取余（%）** → **加（+）、减（-）**。同一优先级时从左到右计算。

> 真题示例：计算 `5 * 4 // 2 ** 2 % 3` 的值。先算 `2**2 = 4`，再从左到右：`5*4 = 20`，`20//4 = 5`，`5%3 = 2`。答案为 2。

关系运算符（>、<、==、!=、>=、<=）的结果是布尔值 True 或 False。逻辑运算符 `and`（与）、`or`（或）、`not`（非）用于连接关系表达式，结果仍为布尔值。

#### 分支语句

Python 使用 `if-elif-else` 处理多分支选择。注意 `elif` 和 `else` 后面不需要再写判断条件——只有 `if` 和 `elif` 后面跟条件表达式，`else` 后面直接跟冒号。语句组相对于关键字必须有**缩进**，这是 Python 区分代码块的方式，也是判断题的常见考点。

```python
# 密码强度检测示例
if x == 3:
    print("强")
elif x == 2:
    print("中等")
else:
    print("弱")
```

#### 循环语句

`for` 循环用于已知循环次数的场景，常配合 `range()` 函数使用：`range(5)` 生成 0,1,2,3,4。`while` 循环用于条件控制的场景，先判断条件为 True 才执行循环体。操作题中常见要求是补全循环体代码，如遍历列表求和、找最大值、统计满足条件的元素个数。

```python
# 统计班级总捐书量
books = [3, 5, 2, 7, 4]
total = 0
for b in books:
    total += b
print("总捐书量:", total)

# 找最大值
max_val = books[0]
for b in books:
    if b > max_val:
        max_val = b
print("最大值:", max_val)
```

> 操作题中 Python 部分主要考查阅读、修改和补全程序的能力，很少要求从零编写。重点掌握：变量的赋值与累加、列表遍历、条件判断、字符串操作（如统计字符类别）。把上面两类代码模板练熟，考场上基本能应对。

### 第五章 数据处理和可视化表达

本章主要考查 WPS 表格 / Excel 的数据处理能力，是操作题的另一大块（约 15 分）。

#### 常用函数

| 函数 | 功能 | 示例 |
| --- | --- | --- |
| SUM | 求和 | =SUM(B3:B12) |
| MAX | 求最大值 | =MAX(B3:B12) |
| MIN | 求最小值 | =MIN(B3:B12) |
| AVERAGE | 求平均值 | =AVERAGE(B3:B12) |
| IF | 条件判断 | =IF(AND(E3>=18.5,E3<=25),"正常","注意体重") |

#### 图表类型

| 图表 | 适用场景 | 特点 |
| --- | --- | --- |
| 柱形图 | 跨类别比较 | 柱子高度反映数据差异 |
| 折线图 | 按时间呈现趋势 | 强调变化幅度 |
| 饼图 | 呈现比例 | 反映部分占整体的比重 |
| 雷达图 | 多维数据整体关系 | 只能将一维数据映射到坐标轴 |

真题中的典型操作题要求：用 MAX 函数计算各项目最大值、用公式计算 BMI 指数（保留两位小数）、用 IF 函数根据 BMI 值填写健康信息、以指定数据源生成簇状柱形图并设置图表标题，最后保存文件。

### 第六章 人工智能及其应用

需要区分人工智能的应用场景与非应用场景。自动驾驶、语音对话、车牌识别、语音输入法都属于人工智能应用；而远程遥控操作机器人、校园一卡通远程充值则不属于典型的人工智能应用（前者是遥控操作，后者是传统信息系统）。

人工智能的发展阶段包括：运算智能（计算速度快）、感知智能（能"看"能"听"，如图像识别、语音识别）、认知智能（能理解和推理）。目前的 AI 在感知能力上进步巨大，但**不具备主动思考和自主意识**——判断题"在人工智能感知阶段，机器可以像人那样感知世界、主动思考"的说法是错误的。

## 04 模块二：信息系统与社会核心考点

本模块对应必修二，涵盖信息系统的组成要素、硬件与软件、网络基础、信息系统开发流程、信息安全与社会责任。综合应用题的两道大题几乎全部出自这一模块。

> 图3：模块二各章考点重要程度评估

### 第一章 信息系统的组成

信息系统是一个由**人、硬件、软件、网络和数据资源**构成的人机交互系统。五个要素缺一不可：

| 要素 | 说明 | 举例 |
| --- | --- | --- |
| 人 | 使用者、维护者、管理者和设计者 | 学生、系统管理员 |
| 硬件 | 信息系统的物理载体 | 键盘、显示器、CPU、硬盘、路由器 |
| 软件 | 系统软件 + 应用软件 | 操作系统、电商平台 |
| 网络 | 将设备进行物理连接的平台 | 局域网、互联网 |
| 数据资源 | 系统处理和存储的对象 | 学生成绩表、用户信息 |

#### 硬件分类

| 类别 | 功能 | 常见设备 |
| --- | --- | --- |
| 输入设备 | 向系统输入信息 | 键盘、鼠标、摄像头、传感器、麦克风 |
| 输出设备 | 输出处理结果 | 显示器、打印机、音箱 |
| 处理设备 | 执行计算和控制 | CPU（中央处理器） |
| 存储设备 | 存储数据 | 内存（RAM）、硬盘、U盘 |
| 网络设备 | 连接和转发数据 | 路由器、交换机、光猫 |

> **易错点**
>
> **内存**（RAM）断电后数据会丢失，**硬盘**断电后数据不会丢失。判断题经常把两者混淆。"内存越大，计算机运行速度越快"的说法有一定道理但不严谨——影响速度的是 CPU 性能、内存大小、硬盘读写速度等多因素的综合。

#### 软件分类

**系统软件**负责控制和管理硬件资源，典型如操作系统（Windows、Linux、Ubuntu）。**应用软件**为特定目的开发，如办公软件（WPS Office）、电商平台 APP。开源软件的特点是源代码开放获取，可集全世界编程者的智慧来改进——但它不是"系统软件"，也不是"必须付费使用"的。

### 第二章 信息系统开发

#### B/S 与 C/S 模式

信息系统有两种工作模式：**B/S**（Browser/Server，浏览器/服务器）模式通过浏览器访问，无需安装客户端；**C/S**（Client/Server，客户端/服务器）模式需要安装专门的客户端软件。例如，使用 HTML、JavaScript 编写前端、Asp.NET 编写后端的选科系统属于 B/S 模式。

#### 开发流程

信息系统开发的完整流程包括：**需求分析 → 系统设计 → 编码 → 软件测试 → 部署运行**。真题常给出若干开发步骤让学生排序或判断。几个易错判断：

需求分析是开发的前提，**不是可有可无的环节**。数据库结构设计（如用 Access 创建数据库表）为系统发布后的"存储"功能做好准备。自行开发的系统同样存在信息泄漏风险，不能因为"同学自行开发"就放心输入个人信息。

#### 数据库管理软件

对大量数据进行计算机管理，应选择数据库管理软件如 Access，而非 Word、PPT 或 Photoshop。这是选择题中的常见辨析题。

### 第三章 网络基础

网络是综合应用题的固定考点，以家庭组网为情境考查网络设备、地址、协议等知识。

#### 关键概念

| 概念 | 说明 |
| --- | --- |
| IP 地址 | 网络中终端设备的唯一标识，如 192.168.0.1 |
| 子网掩码 | 划分网络地址和主机地址，常见如 255.255.255.0 |
| 网关 | 连接不同网络的"出口"，通常是路由器地址 |
| DNS | 域名解析服务器，将域名转换为 IP 地址 |
| WAN | 广域网（Wide Area Network），覆盖范围大 |
| LAN | 局域网（Local Area Network），覆盖范围小如家庭/学校 |

#### 家庭组网场景

典型真题情境：光纤入户（FTTH），运营商提供光猫，家庭另购无线路由器。光猫的 LAN 口通过双绞线连接到路由器的 WAN/LAN 自适应网口。光猫的作用是光信号与电信号之间的转换，**不是光信号与模拟信号的转换**——这是判断题的常见陷阱。

路由器配置要点：选择"自动获取 IP 地址"时终端无需手动配置 IP；同一子网内终端 IP 地址范围为 192.168.0.2 到 192.168.0.254；通过 WiFi 上网的手机同样需要 IP 地址（由路由器自动分配）；剩余的 LAN 端口可连接台式电脑、带网络接口的打印机或交换机。

### 第四章 信息安全与社会责任

#### 信息安全风险与防范

信息系统面临的安全风险包括：硬件故障、软件漏洞、恶意攻击（病毒、木马、黑客入侵）、人为操作失误。基本防范措施：设置高强度密码（数字+字母+特殊符号三类字符的组合）、使用验证码区分操作者是人还是计算机、定期备份重要数据、安装杀毒软件和防火墙。

#### 个人信息安全

个人信息的采集方式包括：网络日志采集、爬虫采集、传感器采集（如智能锁采集人脸/指纹）、搜索引擎检索。在日常使用中应注意：不在不明来源的系统输入个人敏感信息，即使是同学自行开发的系统；定期更换密码；不随意连接公共 WiFi 进行涉及隐私的操作。

#### 信息社会责任

信息社会的基本特征包括信息经济、网络社会、数字生活和在线政府。国家中小学智慧教育平台随时随地可学习课程，体现的是数字生活特征。无人超市节省购物时间、减少人工成本——但"商品质量更好"不属于无人超市相比传统超市的优点，这是选择题的排除项。

## 05 复习时间规划

以考试在 1 月中旬为基准，从 9 月开学到考试的复习周期约 4 个月。以下规划按四个阶段推进，每阶段有明确的目标和侧重点。

1. **9月 — 基础梳理期**
   系统过一遍两个模块的教材和课堂笔记，建立知识框架。重点完成必修一第一章至第四章的概念学习，配合每章课后练习。每周安排 2–3 次上机实践，熟悉 Python IDLE 和 WPS 表格的基本操作环境。目标：所有知识点至少见过一遍，知道每个概念大概在讲什么。

2. **10月 — 专项突破期**
   按题型和模块做专题训练。选择题用知识点清单逐一刷题，标记错题和不确定的题目；操作题开始动手写 Python 代码，重点练习列表遍历、条件判断、累加求和、找极值等基本编程模式；Excel 操作题练习 SUM、MAX、IF 函数和图表生成。每天 30–40 分钟，穿插选择题与操作题。目标：选择题正确率达到 80% 以上，Python 操作题能独立完成基本编程任务。

3. **11月 — 真题模拟期**
   集中做近 3 年河南省真题和模拟题，按正式考试时间（45 分钟）限时完成。每套真题做完后逐题分析：选择题查缺补漏，操作题检查代码和 Excel 操作是否有遗漏步骤。整理错题本，把反复出错的知识点单独标注。目标：真题卷面分稳定在 80 分以上，错题率持续下降。

4. **12月 — 1月 冲刺巩固期**
   回顾错题本和易错知识点，重点突破薄弱环节。针对操作题做 5–8 套限时训练，确保 Python 编程和 Excel 操作流程熟练到"肌肉记忆"程度。考前一周不做新题，只看错题和知识点清单，保持手感。考前几天熟悉机考环境操作（如文件保存、交卷流程），避免因操作不熟而丢分。

## 06 高频考点与易错警示

根据近年真题分析，以下考点反复出现，且容易出错。考前务必逐一核对，确保掌握。

### 选择题高频考点

| 考点 | 频次 | 常见陷阱 |
| --- | --- | --- |
| Python 文件扩展名 | **高频** | 答案是 .py，与 .doc/.png/.pdf 区分 |
| 音频数据量计算 | **高频** | 忘记除以 8（bit→Byte），或混淆声道数 |
| 大数据 4V 特征 | **高频** | "价值密度低"常被偷换为"价值密度高" |
| Python 运算符优先级 | **高频** | 幂运算最高，同级从左到右 |
| 枚举算法判断 | **中频** | 需判断答案范围是否有限可列举 |
| 程序设计流程顺序 | **中频** | 分析→设计→编写→调试，不可打乱 |
| 人工智能应用辨析 | **中频** | 遥控操作≠AI，一卡通充值≠AI |
| 信息系统组成要素 | **中频** | 人、硬件、软件、网络、数据，五要素缺一不可 |

### 判断题高频考点

| 判断题题干（缩略） | 答案 | 关键辨析 |
| --- | --- | --- |
| 同样的数据，不同人可能获得不同信息 | 对 | 信息获取与接收者知识背景有关 |
| 高级语言比机器语言执行效率高 | 错 | 机器语言执行效率最高，高级语言便于编写 |
| 断电后内存数据会丢失 | 对 | RAM 是易失性存储 |
| AI 感知阶段机器可主动思考 | 错 | 感知≠思考，当前 AI 不具备自主意识 |
| WPS Office 可处理文字/表格/演示文稿 | 对 | WPS 是集成办公套件 |

### 操作题易失分点

> **Python 编程题**：最常见的失分原因是缩进错误（Python 对缩进敏感）、变量名拼写错误、循环边界搞错（range 的上界不含）。补全代码时务必对照流程图，按步骤逐一填写。

> **Excel 操作题**：最容易丢分的步骤是忘记保存文件——很多同学做完所有操作后直接关闭窗口，没有点击保存，导致整个操作题零分。此外，BMI 公式中的除号要用 `/` 而非 `÷`，IF 函数的条件用 `AND()` 连接多个条件，图表数据源区域要精确选择（如 A2:B12 而非 A1:B12）。

> 机考环境中文件操作有严格规范：每道操作题在指定文件夹下打开指定文件，完成后必须保存并关闭，不能关闭 WPS 软件本身（后续题目可能还需要使用）。这些操作习惯在日常练习中就要养成，不要等到考场才适应。

## 07 备考实战建议

### 选择题：用"排除法 + 错题归因"

选择题覆盖面广但单题分值不高（每题 2 分），不必在难题上纠结太久。遇到不确定的题目先标记，用排除法去掉明显错误的选项。做完后对答案时，重点不是"这道题选什么"，而是"我为什么选错了"——是概念记混了、公式用错了、还是没读懂题干情境。把错因记在错题本上，比刷十套新题更有效。

### Python 操作题：手写代码而非看代码

很多同学"看懂了"代码但"写不出来"。Python 操作题的本质是阅读理解 + 补全填空，但补全的部分需要你自己根据流程图或题目要求推算出来。建议：找 10–15 道历年真题操作题，先不看答案自己尝试补全，再对照答案找差距。重点练习以下代码模式：

```python
# 模式一：遍历列表求和/计数
total = 0
for item in data_list:
    if item > 0:      # 满足某条件
        total += item
print(total)

# 模式二：分类统计字符
digit_count = letter_count = other_count = 0
for ch in password:
    if ch.isdigit():
        digit_count += 1
    elif ch.isalpha():
        letter_count += 1
    else:
        other_count += 1
# 根据三类计数判断密码强度
```

### Excel 操作题：按步骤逐一核对

Excel 操作题的评分是按步骤给分的，每一步操作对应明确的分值。做题时严格按照题目编号顺序执行：先计算最大值/平均值，再算公式（如 BMI），再用 IF 函数填列，再生成图表，最后保存。中间任何一步遗漏都会影响后续步骤的连锁得分。做完后回头检查一遍文件是否已保存。

### 综合应用题：理解信息系统"全局观"

综合应用题的两道大题分别围绕家庭组网和信息系统开发展开。这两道题虽然形式灵活，但考查的是系统性的理解：组网题需要理解信号从光纤到终端的完整链路（光猫→路由器→终端），开发题需要理解从需求到部署的完整流程。复习时不要孤立记概念，而要把这些概念串成一条完整的链路。

### 考前一周的安排

考前最后阶段不建议再做大量新题。核心任务有三项：第一，翻阅错题本，重做所有错过的题；第二，把音频数据量公式、运算符优先级、程序设计流程、信息系统五要素、网络设备对照表等核心知识再默写一遍；第三，做 1–2 套真题保持手感，限时完成，模拟真实考试节奏。考试当天提前到达考场，熟悉机位环境，深呼吸后开始做题——这是一场合格性考试，放平心态，按部就班，通过的把握很大。
