# 第十一套信息技术试题答案与解析表

| 题号 | 题型 | 答案 | 核心解析 |
|------|------|------|----------|
| 4 | 单选 | B | `COUNT`函数功能：统计**数值型数据**的个数。A3:A7共5个单元格，若均为数值，则①处结果为5；A错误，C/D错误（B3:B7若有数值则结果不为0或6）。 |
| 6 | 单选 | B | 无线通信技术特性：<br>- A 正确：Wi-Fi是无线局域网技术，通过无线电波联网；<br>- B 错误：Bluetooth（蓝牙）是**短距离**无线通信技术，可在手机、无线耳机间传输数据；<br>- C 正确：NFC是短距离高频技术，可模拟门禁卡；<br>- D 正确：RFID是射频识别技术，非接触双向通信。 |
| 11 | 单选 | B | 二进制基本规则：<br>- A 错误：二进制基本数码只有`0`和`1`；<br>- B 正确：运算规则是**逢二进一，借一当二**；<br>- C 错误：二进制数后缀是`B`，十进制后缀是`D`；<br>- D 错误：二进制正整数最低位权值是$2^0=1$。 |
| 13 | 单选 | A | Python `min()`函数：返回列表中的**最小值**。列表`[3,5,8,1]`的最小值是`1`。 |
| 20 | 单选 | （需结合图形符号选项，核心判断依据：虚线框功能） | 流程图符号规则：<br>- 起止框：圆角矩形（表示开始/结束）；<br>- 判断框：菱形（表示条件判断）；<br>- 处理框：矩形（表示计算/赋值）；<br>- 输入输出框：平行四边形（表示数据输入/输出）。<br>需根据虚线框在流程图中的作用匹配对应符号。 |
| 21 | 判断 | √ | 流程图各类框的符号不同：起止框（圆角矩形）、输入输出框（平行四边形）、处理框（矩形）、判断框（菱形），功能与符号一一对应。 |
| 22 | 判断 | × | 系统软件包含：操作系统（如Linux）、语言处理程序（如Python解释器）、数据库管理系统等。Python语言处理程序**属于系统软件**，题干后半句表述错误。 |
| 26[1] | 选填 | 感知层 | 物联网三层架构：**感知层**负责数据采集（如传感器、红外探测器）；应用服务层负责为用户提供具体服务（如APP控制）。 |
| 26[2] | 判断 | × | 任何信息系统的五大组成要素都包含**人员**，智能家居系统需要人员进行安装、配置、操作和维护。 |
| 26[3] | 单选 | C | 信息系统组成要素：传感器是**硬件设备**，用于采集物理数据；软件是程序，数据是处理对象，网络是传输通道，均不匹配。 |
| 26[4] | 单选 | B | 烟雾传感器的核心功能是**采集环境中的烟雾浓度数据**；显示数据是终端设备功能，处理/存储数据是服务器功能。 |
| 26[5] | 多选 | ABC | 软件性能需求包括：**安全性**（防止非法入侵）、**稳定性**（长期运行不崩溃）、**易用性**（操作简单）；合理性属于功能设计范畴，不属于性能需求。 |
| 27[1] | 选填 | 交换机 | 网络设备功能：**交换机**提供多个网络端口，可连接多台计算机并转发内网数据；调制解调器负责信号转换（光→电/电→光）。 |
| 27[2] | 判断 | √ | 设备A是光猫，核心功能就是**实现光信号与电信号的相互转换**，通过光纤接入互联网，是家庭/办公室联网的必备设备。 |
| 27[3] | 单选 | C | 域名后缀含义：`.edu`是**教育机构**的专用后缀（`pku.edu.cn`是北京大学域名）；`.com`是商业组织，`.gov`是政府机构，`.mil`是军事组织。 |
| 27[4] | 单选 | C | 带宽换算步骤：<br>1. 下载速度 = $125\mathrm{MB}÷10\mathrm{s}=12.5\mathrm{MB/s}$；<br>2. 带宽（bit/s）= 下载速度 × 8 = $12.5×8=100\mathrm{Mb/s}$。 |
| 27[5] | 多选 | BCD | 无线路由器参数分析：<br>- A 错误：路由器连接设备数远大于4台（取决于带宽和设备性能）；<br>- B 正确：默认用户名和密码多为`admin`；<br>- C 正确：开启DHCP后，分配的IP属于局域网网段（如`192.168.1.x`）；<br>- D 正确：光猫（A）和路由器（B）通过**双绞线（网线）**连接（光猫LAN口→路由器WAN口）。 |
