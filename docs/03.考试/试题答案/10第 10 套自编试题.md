# 第十套信息技术试题答案与解析表

| 题号 | 题型 | 答案 | 核心解析 |
|------|------|------|----------|
| 4 | 单选 | B | 网络打印机属于**硬件设备**，办公室老师通过局域网共用打印机，本质是**硬件资源共享**；信道资源是传输通道，软件/数据资源共享与打印机无关。 |
| 5 | 单选 | B | 数制转换验证：<br>- A 错误：二进制`111` = 十进制`7` = 八进制`7`，不是`6`；<br>- B 正确：二进制`101` = $1×2^2+0×2^1+1×2^0=5$；<br>- C 错误：十进制`10` 转换为二进制是`1010`，不是`1011`；<br>- D 错误：二进制`10`（末位0）= 十六进制`2`（末位非0）。 |
| 8 | 单选 | C | WPS表格的文件层级关系：**工作簿**（后缀`.xlsx`）包含多个工作表；单元格是最小数据单位，数据库/二维表是数据组织形式，不是文件概念。 |
| 11 | 单选 | C | 存储容量单位换算：$1\mathrm{GB}=1024\mathrm{MB}=1024×1024\mathrm{KB}=1024×1024×1024\mathrm{B}$；1GB视频文件的容量远大于其他选项。 |
| 14 | 单选 | D | 按年龄划分儿童票优惠标准，需要**判断年龄区间→执行不同的票价规则**，对应**分支（选择）结构**；循环结构用于重复操作，顺序结构无判断逻辑，树形结构不属于算法控制结构。 |
| 19 | 单选 | A | 伪代码的特点：用类程序语言的简洁语句描述算法，**易于转化为Python、C语言等计算机程序设计语言**；<br>- B 错误：流程图用图形符号，伪代码用文字；<br>- C/D 错误：伪代码书写方便、表达简洁、易于理解。 |
| 21 | 判断 | × | 字符“A”ASCII码十进制`65`，则“D”的十进制ASCII码是`68`；十六进制`44` 转换为十进制是 $4×16+4=68$。题干表述逻辑混乱，未明确进制对应关系，判定为错误。 |
| 22 | 判断 | × | Python运算优先级：先乘除取模，后加减。<br>计算步骤：$5×8=40$ → $40\%3=1$ → $1+6=7$；结果是`7`，不是`16`。 |
| 24 | 判断 | √ | 传感器的核心定义：感知被测信息，并将其按规律转换为电信号或其他形式，满足传输、处理等需求，题干描述与定义完全一致。 |
| 25 | 判断 | × | WPS表格**分类汇总的前提条件**：必须先对**分类字段进行排序**，否则会出现同一类别多次汇总的错误结果。 |
| 26[1] | 选填 | 交换机 | 设备A（路由器）下联设备B的功能是**扩展有线端口，连接多台学生机**，符合交换机的定位；路由器用于连接外网，集线器性能弱于交换机，均不匹配。 |
| 26[2] | 判断 | √ | 在小型局域网中，路由器通常承担**网关**的角色（负责内网与外网的数据包转发），路由器的LAN口IP地址就是内网设备的网关地址。 |
| 26[3] | 单选 | D | 能上QQ（基于IP地址通信），但无法打开网页（需要域名解析为IP），故障原因是**DNS配置不正确**；POP3是邮件接收协议，FTP是文件传输协议，Telnet是远程登录协议，均与网页访问无关。 |
| 26[4] | 单选 | B | 按网络规模和地理范围划分，学校机房的网络属于**局域网（LAN）**，特点是小范围、高传输速率；城域网覆盖城市，广域网跨地域（如因特网）。 |
| 26[5] | 多选 | ABCD | IP地址的合法规则分析：<br>- A 错误：`192.168.1.256` 中`256`超出IPv4地址单段`0-255`的取值范围；<br>- B 错误：`255.255.255.0` 是子网掩码，不是主机IP地址；<br>- C 错误：`192.168.1.254` 是网关地址，不能分配给学生机；<br>- D 错误：`192.168.1.34` 与学生机1的IP重复，会导致网络冲突。 |
| 27[1] | 选填 | 总体设计 | 系统开发阶段划分：**总体设计**是规划系统的整体架构、功能模块划分；详细设计是对单个模块的内部逻辑、算法进行细化，功能模块结构图属于总体设计范畴。 |
| 27[2] | 判断 | × | 任何信息子系统（包括机场物联网的子系统），都必须具备**输入、存储、处理、输出、控制**五大核心信息处理功能，缺一不可。 |

| 27[4] | 单选 | C | 感应电子标签识别货物信息，运用的是**RFID（射频识别）技术**，属于非接触式自动识别技术；Wi-Fi、蓝牙、ZigBee是无线通信技术，不用于电子标签识别。 |
| 27[5] | 多选 | ABC | 机场物联网系统的安全风险防范措施：<br>- A 正确：数据容灾备份可防止数据丢失，保障完整性；<br>- B 正确：防火墙可隔离内外网，拦截非法访问；<br>- C 正确：数据加密可防止传输过程中被窃取篡改；<br>- D 错误：所有用户权限相同会导致越权访问，增加安全风险。 |
