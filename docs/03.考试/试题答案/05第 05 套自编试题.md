## 第 5 套试题答案与解析

| 题号 | 题型 | 答案 | 核心解析 |
|------|------|------|----------|
| 2 | 单选 | C | **交叉分析法**的定义就是从横向、纵向两个维度，计算有联系变量在交叉点的统计值；变量分析法、双向分析法、个体分析法均不符合该特征。 |
| 3 | 单选 | D | 计算机硬件系统由**运算器、控制器、存储器、输入设备、输出设备**五大基本部件组成；RAM和ROM都属于存储器的细分类型，不能替代“存储器”这一总称。 |
| 4 | 单选 | A | 智能空调根据室温调整工作状态，依赖**温度传感器**采集室温数据；压力传感器用于测压力、红外传感器用于感应红外信号、光敏传感器用于感应光线强度，均不匹配需求。 |
| 6 | 单选 | A | 顺序结构是算法的基本控制结构之一，特点是**自上而下**按代码或步骤的书写顺序依次执行；与数值大小（从大到小/从小到大）无关。 |
| 8 | 单选 | B | 常用的算法描述方法有**自然语言、流程图、伪代码**三种；A错误，流程图可用于人工梳理算法逻辑，不局限于计算机；C错误，伪代码是简化描述，不与程序语句一一对应；D错误，自然语言描述算法容易产生歧义。 |
| 9 | 单选 | A | 图像数字化的核心步骤是**采样**，即按一定间隔纵、横分割图像成若干像素点；B错误，1024×768指1024行、768列像素；C错误，像素存储位数由色彩深度决定（如24位真彩色一个像素占24位）；D错误，像素点越多，存储空间越大。 |
| 17 | 单选 | B | Python中算术运算符包括`%`（取模）、`/`（除法）、`**`（幂运算）；`or`是**逻辑运算符**，用于逻辑“或”判断。 |
| 21 | 判断 | × | 智能手机的中央处理器（CPU）由**运算器和控制器**组成；存储器是独立于CPU的硬件部件。 |
| 22 | 判断 | √ | 声音数字化的步骤包括采样、量化、编码，**采样**就是每隔固定时间在模拟声音波形上取一个幅度值。 |
| 25 | 判断 | √ | `while`循环是**当型循环**，逻辑是“当循环条件成立时，执行循环体”；条件不成立则跳出循环。 |
| 26[1] | 选填 | PON | 光纤接入光猫时，需连接专用的**PON口**（无源光网络接口）；LAN口用于连接路由器或内网设备。 |
| 26[2] | 判断 | √ | 按网络规模和地理范围划分，网络分为局域网（LAN）、城域网（MAN）、广域网（WAN），**因特网属于广域网**。 |
| 26[3] | 单选 | B | 复制操作的数据会临时保存在**内存储器（内存）** 中，内存的特点是断电后数据丢失；因此停电后“粘贴”功能失效，因为临时数据已丢失。 |
| 26[5] | 多选 | AD | 同一局域网内的设备IP地址需处于同一网段，智能手机的IP网段为`192.168.68.x`，因此台式机和笔记本的IP也需属于该网段；`192.168.68.255`是该网段的广播地址，不能分配给主机；`192.168.67.68`属于不同网段。 |
| 27[1] | 选填 | 超声波 | 无人值守停车场检测车位状态，常用**超声波传感器**（通过发射和接收超声波判断车位是否有车）；温度传感器用于测温度，与车位检测无关。 |
| 27[2] | 判断 | √ | 摄像头自动识别车牌号，属于**人工智能的图像识别技术**，通过训练好的模型匹配车牌特征。 |
| 27[3] | 单选 | D | 无人值守停车场系统整合了传感器、摄像头、网络、智能控制等技术，属于**物联网**的典型应用；增强现实、虚拟现实侧重虚实交互，深度学习是人工智能的一个分支，均不能涵盖整个系统技术。 |
| 27[4] | 单选 | D | 信息系统的基本功能包括输入、存储、处理、输出；付费后抬杆放行，是系统向外界输出“放行”的执行动作，属于**输出功能**。 |
| 27[5] | 多选 | ABCD | 无人值守停车场的优势：A提升用户体验（无需停车取卡）；B防止乱收费错计费（系统自动核算）；C提高通行速率（不停车通行）；D节省人力成本（无需人工值守）。 |
