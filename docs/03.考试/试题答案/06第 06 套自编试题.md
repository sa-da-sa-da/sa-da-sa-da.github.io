# 第六套信息技术试题答案与解析表

| 题号 | 题型 | 答案 | 核心解析 |
|------|------|------|----------|
| 5 | 单选 | B | 算法执行逻辑需**先获取数据、再计算、最后输出结果**：②输入半径`r`→①计算面积`s=π×r×r`→③输出面积`s`，顺序符合数据处理流程。 |
| 13 | 单选 | D | 身份证号判断男女的逻辑：需先验证长度（18位），再取第17位判断奇偶，存在**双分支/多分支结构**，并非单分支；A正确，嵌套分支缩进量不同；B正确，第二行用于长度校验；C正确，第一行实现输入功能。 |
| 14 | 单选 | D | 域名后缀含义：`gov`→**政府机构**，`com`→**商业组织**，`edu`→**教育机构**，需牢记常见域名后缀的对应属性。 |
| 15 | 单选 | A | 信息系统安全风险的核心分类：硬件风险、软件风险、数据风险、**网络风险**；控制风险、备份风险、加密风险均属于风险防控相关的细分项，而非系统构成层面的风险类型。 |
| 17 | 单选 | B | 算法的4个基本特征：**可行性、确定性、有穷性、有输出**；输入不是必须的（允许0个输入，如输出固定值的算法），因此“至少有一个输入”不属于基本特征。 |
| 21 | 判断 | √ | 移动终端（手机、平板）与计算机的结构逻辑一致，均包含**输入、处理（运算+控制）、存储、输出**四个核心部分，功能模块对应匹配。 |
| 23 | 判断 | × | 模块化设计是将复杂算法拆分为独立功能模块，**既能降低设计难度，又能提升程序的可读性和可维护性**（便于单独调试、修改），题干后半句表述错误。 |
| 24 | 判断 | × | `print(12)`输出的是**整数类型**的12，`print("12")`输出的是**字符串类型**的12；虽然输出显示结果相同，但数据类型完全不同，运算规则也有差异。 |
| 26[1] | 选填 | 输入 | 气象采集、棚内采集是**向信息系统输入原始数据**的过程；输出是系统向外反馈结果（如控制指令），存储是保存数据，均不符合该环节功能。 |
| 26[2] | 判断 | √ | 智慧农业系统的闭环逻辑：温度传感器采集数据→网络传输至平台→平台分析数据→根据阈值控制遮阳帘、风机，符合物联网“感知-传输-处理-控制”的工作流程。 |
| 26[3] | 单选 | C | 气象、棚内、视频数据的采集，核心依赖**传感器设备**（如温度传感器、湿度传感器、摄像头）；显示器是输出设备，运算器、控制器属于CPU部件，不负责数据采集。 |
| 26[4] | 单选 | （需结合流程图选项，核心逻辑：采集土壤湿度→判断≥设定值？→是则不浇灌→否则启动浇灌→结束） | 土壤湿度控制的算法逻辑为**分支结构**，关键判断节点是“测量值≥设定值”，符合智慧农业的自动化控制流程。 |
| 26[5] | 多选 | ABCD | 智慧农业管理系统的正常运行依赖全链路组件：服务器故障会导致数据处理中断，网络故障会导致数据传输失败，传感器损坏会导致数据采集失效，控制设备损坏会导致执行指令无法落地。 |
| 27[1] | 选填 | PON | 入户光纤需连接光猫（设备①）的**PON口**（无源光网络专用接口）；LAN口用于连接内网设备（如路由器），不能直接接入光纤。 |
| 27[2] | 判断 | × | 设备②（路由器）的WAN口用于连接外网，LAN口用于连接内网设备，两者IP地址**必须处于不同网段**（如WAN口为公网IP，LAN口为私有IP），否则会出现网络冲突。 |
| 27[3] | 单选 | C | 设备②需要实现“有线转无线、多设备联网、共享外网”的功能，**无线路由器**完全匹配需求；防火墙侧重安全防护，调制解调器侧重信号转换，交换机侧重有线设备扩展，均不符合。 |
| 27[4] | 单选 | D | 光猫（设备①）与无线路由器（设备②）的连接规则：网线一端插光猫的**LAN口**（输出内网信号），另一端插路由器的**WAN口**（接入外网信号），此为家庭网络的标准连接方式。 |
| 27[5] | 多选 | CD | 网络终端设备是**直接供用户使用的终端**（如电脑、手机）；路由器、交换机属于**网络通信设备**，用于数据转发和网络扩展，不属于终端设备。 |
