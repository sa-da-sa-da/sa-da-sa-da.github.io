### 补充：29题闰年判断完整Python程序（可直接运行）
```python
# 输入年份并转换为整数
year = int(input("请输入一个年份："))

# 闰年判断逻辑
if year % 4 == 0:  # 第一步：判断能否被4整除
    if year % 100 == 0:  # 第二步：判断能否被100整除
        if year % 400 == 0:  # 第三步：判断能否被400整除
            print(f"{year}是闰年")
        else:
            print(f"{year}不是闰年")
    else:
        print(f"{year}是闰年")
else:
    print(f"{year}不是闰年")

# 测试用例：
# 输入2000 → 输出“2000是闰年”（能被400整除）
# 输入1900 → 输出“1900不是闰年”（能被100整除但不能被400整除）
# 输入2024 → 输出“2024是闰年”（能被4整除且不能被100整除）
# 输入2023 → 输出“2023不是闰年”（不能被4整除）
```

### 总结
1. **核心语法/算法**：
   - 代数式转Python表达式需注意括号（保证运算优先级）、平方用`**`；
   - 闰年判断逻辑：能被4整除且不能被100整除，或能被400整除，核心是`%`取模运算。
2. **物联网/智能系统**：
   - 感知层=传感器（采集数据），应用服务层=用户端（App/浏览器）；
   - 智能控制需传感器+通信+控制技术配合，无关传感器损坏不影响核心功能。
3. **网络基础**：
   - 交换机扩展端口，路由器连接外网，双绞线是台式机有线联网的主流介质；
   - 终端能上网、无线设备不能上网→排查无线AP/连接线/终端自身，而非核心路由器。
4. **数制/通信技术**：
   - 数制比较需统一转换为十进制；
   - 近距离通信：WiFi/蓝牙/RFID，远距离：移动通信技术（4G/5G）。
