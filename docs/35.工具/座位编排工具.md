# 智能教室排座系统

- [座位编排工具](https://www.sakaay.com/seat-map/seat-map.html) — 该系统是面向教师的可视化班级座位编排工具，支持自定义教室布局、多维度排座规则、一键智能生成座次表，支持PDF导出，高效完成班级座位安排工作。

## 直接访问
  - 点击 [座位编排工具](https://www.sakaay.com/seat-map/seat-map.html)
  - 地址栏输入：https://www.sakaay.com/seat-map/seat-map.html 并访问.

## ✨核心功能

### 1. 数据准备：快速导入学生名单

- 提供Excel模板下载，支持`.xlsx/.xls`格式文件上传，也可直接粘贴学生名单，批量导入学生基础信息。
- 识别学生性别、身高、视力、成绩等数据，为智能排座提供数据依据。

### 2. 可视化教室布局自定义

- 自由配置教室**行数、列数**，实时预览教室座位画布，点击确定布局锁定教室结构。
- **VIP座位设置**：讲台两侧可配置VIP特殊座位，最多4个；VIP座位不参与智能算法排座，支持手动拖拽分配学生。
- 可视化座位画布：直观展示讲台、VIP座、普通座位、分隔标识，UI区分男生、女生、VIP座位、空座位状态。
- 支持设置列分隔，模拟教室过道效果，还原真实教室环境。

### 3. 多样化智能排座规则

内置多种排座策略，可自由组合勾选：

1. **身高排序**：按照身高从矮到高编排，保证后排学生不遮挡视线。
2. **视力排序**：依据视力情况，视力较差学生优先安排靠前座位。
3. **性别配对**：开启后优化男女学生交错分布，避免同性扎堆。
4. **成绩互勉**：实现好生差生互助穿插排布，促进同学互相学习。
- 勾选规则后点击「智能生成座次表」，算法自动完成全班座位分配。VIP座位保持空置，教师手动拖拽填入学生。

### 4. 成果导出

一键将编排完成的座位表导出为 **PDF文件**，方便打印张贴教室，留存归档。

## 🎯适用场景

中小学班主任、任课教师，快速完成新学期排座、阶段性座位调整；可视化所见即所得，无需手动绘制表格，大幅减少排座耗时。

## 💡使用流程

1. 下载模板整理学生信息，上传学生名单
2. 设置教室行列数，按需开启VIP座位，确定布局
3. 勾选需要的排座规则
4. 智能生成座次，手动调整VIP座位
5. 导出PDF打印使用
