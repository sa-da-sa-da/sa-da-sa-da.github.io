# 随机点名工具

一个支持本地缓存的课堂随机点名小工具。名单保存在浏览器 `localStorage` 中，刷新或关闭后自动恢复，无需注册登录。

## 直接访问

- 点击 [随机点名工具](https://www.sakaay.com/random-roll-call.html)
- 地址栏输入：https://www.sakaay.com/random-roll-call.html 并访问

> **提示**：数据仅存储在当前浏览器 `localStorage` 中，更换浏览器或清除浏览器数据会导致名单丢失，请定期使用「导出」按钮备份。

## 核心功能

- **分组管理**：支持多个班级 / 学段分组，独立管理名单
- **名单持久化**：通过 `localStorage` 保存到本地，浏览器刷新、关闭后自动恢复
- **批量导入**：支持换行、空格、逗号、顿号、分号混合分隔，自动去重
- **不重复抽取**：默认抽过的自动从待点池移除，可勾选「允许重复」
- **JSON 备份**：一键导出全部名单 + 已点记录
- **自定义外观**：字号、背景色、文字色、字体粗细、字体族、每次抽取人数、姓名分隔符
- **快捷键**：`空格` 开始 / 停止，`F` 全屏
