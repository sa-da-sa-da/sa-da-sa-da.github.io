# 考试证件批量生成工具

面向考试考务场景的证件批量生成工具。内置工作证、主考证、监考员证等多种证件类型，自定义证面字段与排版字号，上传照片按文件名自动匹配，勾选本次参考人员即可一张 A4 纸打印 4 张证件，适用于中考、高考、学业水平考试等各类监考、考务证件制作。

## 直接访问

- 点击 [考试证件批量生成工具](https://www.sakaay.com/lab/AI/cfgexam.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/cfgexam.html 并访问

> **提示**：人员名单、照片、证件类型、字段定义与各项设置均保存在浏览器 `localStorage` 中，自动保存、下次打开直接可用。更换浏览器或清除浏览器数据会丢失，正式批量出证前请先清理示例数据。

## 核心功能

<GoogleAd ad-slot="2668661755" />

- **灵活证件类型**：内置常用类型库（工作证、工作人员、主考证、监考员证、保密员、保安证、视频监考员等），可自行增删改、一键恢复默认；表格中也可现场自定义新类型并自动入库
- **自定义人员字段**：姓名 / 单位 / 编号为内置列，可自由增加「身份证号、考场号」等字段，增删改即时联动数据表、证面与导入
- **证面自由排版**：勾选印在证件上的字段并用 ↑↓ 调整顺序；顶部考试名称、证件大字、信息文字、底部制证单位四处字号独立调节
- **统一单位设置**：填写统一单位后，人员未填单位时证面自动带出，免去逐条录入
- **多种数据导入**：
  - Excel / CSV 文件导入（.xlsx / .xls 解析需联网加载组件，不行可另存为 CSV 或直接粘贴）
  - 从 Excel 复制直接粘贴，自动识别 Tab、逗号、分号分隔，智能推断每列含义，支持表头手动对应并「记住」映射，下次导入自动套用
- **照片自动匹配**：支持多选文件或整个文件夹批量上传；设置文件名前缀 / 后缀（如 `photo_zk106_front.jpg` → `zk106`），按编号、姓名等字段自动匹配证照，匹配状态一目了然，也可点击表格缩略图单独更换
- **按名单勾选打印**：粘贴本次参加考试名单（每行一个，也可直接复制 Excel 一列），自动勾选匹配人员、取消其余 —— 只打印该打印的人；全选 / 全不选仅作用于当前搜索结果
- **A4 所见即所得**：右侧按真实 A4 纸张实时预览，每张纸 4 个证件（2×2），不足自动补齐空白格；支持 30% ~ 100% 缩放预览，打印时自动隐藏界面按实际尺寸输出
- **数据安全**：危险操作（清空名单、清空所有数据）带二次确认，清空全部需手动输入「清空」二字，防止误操作

## 使用流程

1. 「自定义设置」配好证件类型与人员字段、证面显示字段
2. 「人员数据」导入名单（Excel / CSV / 粘贴）、上传照片并自动匹配
3. 勾选本次要打印的人员（或粘贴名单一键勾选）
4. 右侧预览确认无误 → 点击「打印A4纸」

> 打印小贴士：纸张选 A4、缩放设为「实际大小」、取消页眉页脚，效果最佳。
