# 作业提交统计系统

面向课堂作业收缴的轻量统计工具。按「日期 + 作业项目」记录每位学生的提交状态，点卡片即可在四种状态间切换，并自动汇总提交率、优秀数、待改数。可与 [座位表系统](https://www.sakaay.com/lab/AI/seat-map.html) 联动，按排座展示与统计。

## 直接访问

- 点击 [作业提交统计系统](https://www.sakaay.com/lab/AI/zytj.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/zytj.html 并访问

> **提示**：名单、座位与每日提交记录均保存在浏览器 `localStorage` 中，更换浏览器或清除浏览器数据会丢失，请定期使用「导出明细 / 导出统计」备份。

## 核心功能

<GoogleAd ad-slot="2668661755" />

- **四态打卡**：未交 📝 / 已交 ✅ / 待改 ⏳ / 优秀 ⭐，点卡片即在状态间切换
- **日期 + 作业项目**：按天、按作业（如「语文作业」「数学 P12」）分别记录，顶部自由切换
- **实时统计**：已提交 X/Y、优秀、待改即时汇总，进度一目了然
- **作业内容区**：按日期 + 作业项目记录当天布置内容，输入即自动保存，导出 CSV 一并带上
- **批量操作**：全选 / 取消选择，批量设为未交 / 已交 / 待改 / 优秀
- **趋势图**：近 7 天提交情况可视化（Canvas 绘制）
- **搜索过滤**：按学生姓名实时筛选
- **名单导入**：每行一个名字直接粘贴；或从 [座位表系统](https://www.sakaay.com/lab/AI/seat-map.html) 导入座次（同浏览器自动识别 / 备份 JSON / 直接读取 seat-map.html）
- **座次表联动**：导入后按实际排座显示，与班级管理保持一致
- **CSV 导出**：明细（含作业内容）与汇总统计两种导出
- **暗色模式**：🌓 一键切换浅 / 深色主题
