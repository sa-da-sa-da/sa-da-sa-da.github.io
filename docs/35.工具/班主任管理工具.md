# 班主任管理工具

一个基于浏览器的班主任管理工具，用于管理班级学生名单、点名记录、班级信息等。

## 直接访问
- 点击 [班主任管理工具](https://www.sakaay.com/class-workbench.html)

- 地址栏输入：https://www.sakaay.com/class-workbench.html 并访问

## 功能清单

| 模块 | 内容 |
| --- | --- |
| 📊 首页仪表盘 | 班级人数/今日待办/待沟通家长/重点学生/材料倒计时/本周日程 6 张统计卡 |
| 📚 学生档案库 | 花名册、座位表、住宿、过敏病史、心理台账、好人好事、违纪台账、特殊学生（8 张） |
| 🕐 考勤请假 | 早操考勤、课间操考勤、请假审批、缺勤登记（4 张） |
| 📈 智能成绩分析 | 多批次考试、自动排名、自动划分尖子生/临界生/学困生、偏科筛查、不及格统计、自动学情小结 |
| 🧹 日常班务 | 值日排班、卫生检查、班干部档案、班会存档、班级活动、安全排查（6 张） |
| 📞 家校沟通 | 家长通讯录、家访记录、师生谈话、班级通知、家长会资料（5 张） |
| 📚 文案素材 | 班规公约、每周计划、工作小结、期末评语、通知范本、班会课件（6 张） |
| ✅ 待办备忘录 | 优先级/截止日/备注、过期提醒 |
