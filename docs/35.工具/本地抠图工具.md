# 本地AI抠图工具

基于 AI 模型的浏览器端图片去背景（抠图）工具。上传人像或任意主体图片，自动识别并去除背景，结果可一键更换底色后下载为 PNG。图片全程不离开浏览器，安全私密。

## 直接访问

- 点击 [本地AI抠图工具](https://www.sakaay.com/lab/AI/koutu.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/koutu.html 并访问

> **提示**：首次使用需联网下载约 40MB 的 AI 量化模型（之后可离线使用）；但图片本身只在本地处理，不会上传到任何服务器，可放心处理含学生的照片。预览区中棋盘格背景代表透明区域。

## 核心功能

<GoogleAd ad-slot="2668661755" />

- **AI 自动去背景**：一键抠出主体，无需手动涂抹选区
- **本地运行**：图片不离开浏览器，隐私安全
- **更换底色**：内置白 / 红 / 蓝底，或用取色器自定义颜色，也可恢复透明
- **下载 PNG**：结果以透明背景或所选底色导出为 PNG 图片
- **进度提示**：实时显示处理进度与日志，便于掌握状态
