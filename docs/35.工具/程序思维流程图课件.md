# 程序是如何"想"的 — 顺序·循环·分支

面向信息技术的交互式教学课件，讲解程序设计的三大基本结构。学生通过拖拽操作亲手搭建流程图，在动手过程中理解顺序、循环与分支的逻辑差异，无需编写任何代码。

## 直接访问

- 点击 [程序思维流程图课件](https://www.sakaay.com/lab/AI/program.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/program.html 并访问

## 核心功能

<GoogleAd ad-slot="2668661755" />

- **概念导入**：以生活实例（起床 → 刷牙 → 吃早饭）类比程序，讲清「什么是程序」「为什么要画流程图」
- **框格拖拽配对**：把开始 / 结束、处理、判断、输入 / 输出四张名称卡片拖到对应形状框格中
- **三大结构案例**：顺序、循环、分支三个由浅入深的案例，把步骤拖入流程图框格完成搭建
- **实时进度条**：显示当前案例的完成进度
- **结构对比表**：一图看懂三种结构在核心问题、框格特点与生活例子上的区别
- **随机实验**：一键随机打乱题目顺序，便于反复练习
- **作答评价**：提交后即时给出评价反馈
- **教师数据面板**：登录后查看学生作答数据（需登录）
