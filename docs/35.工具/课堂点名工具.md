# 课堂点名工具

# 最全创意课堂随机点名神器文档

## 一、介绍 与 直接访问

- 点击 [课堂点名工具](https://www.sakaay.com/seat-map/class-call.html)
- 地址栏输入：https://www.sakaay.com/seat-map/class-call.html 并访问

课堂教学中，老师抛出问题经常遇到全场沉默，学生不愿主动举手回答问题。传统随机点名工具仅仅实现名字滚动随机抽取，形式单调，学生新鲜感消退很快；缺少点名记录，无法统计学生被点到频次；动画效果简陋，甚至会让学生借机走神。

优秀的课堂点名工具，不应当只实现随机选人，更应该作为**调动全场注意力的触发器**，把点名变成课堂趣味互动环节。该工具为纯前端网页应用，打造5套完全不同交互体验的创意点名模式。

## 二、五大创意点名模式

|---|---|---|---|

|深海寻宝|学生名字变为海底生物在屏幕游动；按下下潜，画面变暗，光束搜寻，捕获选中学生，生物样式、颜色随机|活跃气氛、低年级课堂|惊喜+趣味|

## 三、核心功能

### 1. 成长记录体系

1. **XP经验与等级系统**：学生被点到即可增加XP，提升等级，从学徒到精英、传说；名字卡牌边框样式、特效跟随等级变化。学生看待点名不再是“倒霉”，而是获取经验。
2. **答题评价**：学生回答完毕，教师可以对答题表现进行评价，记录课堂表现。
3. **点名记录留存**：保存本节课点名全部记录，包含被点学生、答题情况、奖励情况。
4. **隐私安全**：全部数据保存在浏览器本地，**无需注册账号，不上传云端，保护学生隐私**。

### 2. 班级名单管理

- 新建、切换多个班级，班级之间数据相互隔离。
- 批量粘贴导入学生姓名，支持单条新增、编辑、删除学生。
- 名单导出分享，方便教师之间互相复用班级名单。

### 3. 使用特性

1. 纯HTML网页，**无后端、不需要框架，无需安装软件**；CSS做动画、Web Audio API处理音效、Canvas绘图，浏览器原生技术实现。
2. 离线可用：打开网页即可工作，不需要联网。
3. 抽取标记：已经抽取过的学生做标记，避免一节课内重复点名（手动重置可清除标记）。

## 四、开发设计思路

项目开发难度不在于代码编写，而在于交互细节打磨：
1. **盲盒开箱**：精细调整撕封条、开盖动画时长，配合抖动、发光特效，层层递进营造紧张感。
2. **扭蛋机**：全流程独立音效，调校音效频率、时长，完整还原投币、拉杆、滚落、弹开整套反馈。
3. **深海寻宝**：给海底生物增加随机偏移、变速游动算法，模拟真实生物游动，避免机械生硬。

## 五、操作使用步骤

1. 打开网页，进入**班级管理**，新建班级，批量录入学生姓名。
2. 切换对应班级。
3. 挑选需要的点名模式，点击开始，进行课堂点名。
4. 多班级教学：直接切换班级标签即可。
5. 课前建议：办公室电脑编辑好学生名单，复制保存；课堂电脑打开网页粘贴导入，一分钟完成配置。
> 注意：清除浏览器缓存会丢失本地数据，重要名单建议做好导出备份。

## 六、工具价值

点名是抓取全班注意力的重要契机。用好点名工具，就是掌握课堂节奏；让点名变得有趣，是打造趣味课堂的第一步。
