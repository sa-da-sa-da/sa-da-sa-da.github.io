# 课堂计时器

适用于课堂限时活动的全屏计时工具。提供通用课堂与幼儿教学两种视觉风格，支持快捷预设与自定义时长，精确到百分秒，结束时响铃提醒。

## 直接访问

- 点击 [课堂计时器](https://www.sakaay.com/lab/AI/timerdisplay.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/timerdisplay.html 并访问

## 核心功能

<GoogleAd ad-slot="2668661755" />

- **双模式切换**：通用课堂（科技感深色界面）与幼儿教学（卡通角色 + 连环画）
- **快捷预设**：10 秒、30 秒、1 分钟、3 分钟、5 分钟、10 分钟一键设定
- **自定义时长**：按「分 : 秒」自由输入任意时长
- **百分秒精度**：显示格式为 `分:秒.百分秒`（如 `03:00.00`）
- **开始 / 暂停 / 重置**：三个按钮覆盖全部计时控制场景
- **响铃提醒**：倒计时结束播放铃声，可随时开关
- **场景化标题**：每次计时附带场景提示（如「⏰ 收拾玩具」），便于幼儿理解
- **幼儿专属反馈**：浮动卡通角色、连环画插画与时间到时的庆祝动画
