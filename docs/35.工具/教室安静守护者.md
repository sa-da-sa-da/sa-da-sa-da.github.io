# 班级宠物养成 · 教室安静守护者

班级宠物养成积分系统的「安静守护」版本。核心亮点是接入麦克风实时检测课堂分贝：安静时持续累积能量、吵闹时触发惩罚，班级神树与个人宠物同步成长。让"保持安静"变成全班可见的游戏化目标。

## 直接访问

- 点击 [教室安静守护者](https://www.sakaay.com/lab/AI/treeanimals.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/treeanimals.html 并访问

> **提示**：名单、宠物状态与积分均保存在浏览器 `localStorage` 中，更换浏览器或清除浏览器数据会导致数据丢失，请定期使用「导出备份」存档。

## 核心功能

<GoogleAd ad-slot="2668661755" />

- **安静守护核心**：连接麦克风实时检测课堂音量，超过阈值即判定为吵闹
- **阈值与节律可调**：报警阈值（建议自习 50 dB、讨论 70 dB）、安静达标时长、吵闹容忍时长均可自定义
- **自习 / 朗读双模式**：不同场景匹配不同响度标准
- **能量成长机制**：安静持续累积经验值、吵闹扣减，经验驱动个人等级与班级神树
- **班级神树**：实时显示总能量、等级、经验条及距下一级进度
- **领养专属宠物**：选择伙伴后随成长进化，每升 20 级解锁全新形态
- **顶部倒计时**：内置计时器，支持设置 / 开始暂停 / 重置 / 全屏，便于限时活动
- **多方式导入名单**：支持上传 Excel（.xlsx / .xls）、CSV、TXT，或直接粘贴姓名（每行一个）
- **喂养 / 全班扣除 / 座位编辑**：列数 6 ~ 10 可调，开启编辑模式可调整座位布局
- **保存 / 导出 / 重置**：一键保存进度、导出备份文件、重置当前学科进度
- **成长排行榜**：按等级与经验实时排名
- **教师工作台**：基础规则、奖惩机制、系统管理三个标签页精细配置（奖励 / 惩罚经验值、升级难度系数等）
