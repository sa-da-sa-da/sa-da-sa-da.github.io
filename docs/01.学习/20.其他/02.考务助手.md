⭐ 本地时间显示：网站首页显著位置呈现设备的本地时间，其精准度依托本地系统与先进网络同步保障。
这一功能不仅为师生提供统一时间参照，更在考务场景中发挥关键作用。
如限时练、正式考试等环节，确保全体人员时间认知一致，规避因时间差异引发的考试流程错乱，维护考试公正性与严肃性。

⭐ 限时练安排发布：为各年级提供统一的限时练考试时间安排平台，便于教师、学生及家长及时了解教学进度中的测验计划。
例如，教师可依据此安排提前备课、准备试卷；学生能合理规划学习节奏，进行针对性复习；家长则可从旁协助学生调整状态、监督学习进度。

⭐ 通知考务人员：作为考务信息发布核心渠道，监考老师可实时反馈考场内常见的问题
（如答题卡更换或缺失等关键问题），通过 Webhook 向钉钉群机器人、企业微信群机器人、微信公众号等实时推送消息。

⭐ 通知考场师生：借由公告栏、弹窗提醒二元组合，确保信息即时触达考生与监考员，
极大压缩信息传递周期，提升考务执行效率，有效降低因信息延误或错漏引发的考务风险，为考试组织管理注入强劲动力。

⭐ 优化用户体验：
- 配有两种主题色：黑色和白色；
- 配有全屏、打开公告栏、通知考务、切换主题按钮，一触即达对应需求场景；
- 配置简单，操作方便，安全，几乎免费。

## 二、准备

- 📆 1. 开通阿里云函数计算（其他服务器类型亦可，本文以函数计算为例）
- 📆 2. 开通 GoEasy，实现消息推送
- 📆 3. 拥有 WPS / 金山文档账号、钉钉群或企业微信群
- 📆 4. 拥有一个备案域名或者普通域名（需要解析到大陆以外地区；若使用服务器，也可直接使用 IP 地址，非必需）

## 三、搭建步骤

### 步骤 1：登录账号

1. 登录金山文档。打开 GoEasy 官网。打开阿里云函数计算控制台。

   ![1](https://qiniu.sakaay.com/articlePicture/Sakaay11733316318732583.png)

2. 在 GoEasy 中创建应用（免费的基础版即可），进入详情后复制：**应用名**、**Common key**，再备份 **Client key** 和 **Secret key** 待用。

3. 打开 [https://kdocs.cn/l/cdAt4cAjGC8f](https://kdocs.cn/l/cdAt4cAjGC8f)，另存为副本；在副本中打开 AirScript 脚本编辑器，在"获取公告数据推送"脚本里填入 Common key、应用名到对应位置。

   ![2](https://qiniu.sakaay.com/articlePicture/Sakaay11733316469592564.png)

```javascript
// —— WPS AirScript（金山文档脚本编辑器内运行）示例 ——
const sheet = Application.Sheets('发布公告');
const goEasykey = ''; // 填入你的实际 appkey（Common key）
const appname   = ''; // 填入你的实际应用名

// 下方省略 GoEasy 推送相关业务代码，请在 WPS AirScript 编辑器中按官方文档补全。
```

### 步骤 2：授权服务并获取 webhook 地址

4. 授权服务：获取"获取限时练时间(hqsj)"与"获取公告数据推送"的 webhook 地址。

   ![3](https://qiniu.sakaay.com/articlePicture/Sakaay11733317207715151.png)
   ![4](https://qiniu.sakaay.com/articlePicture/Sakaay11733317264208648.png)

### 步骤 3：阿里云函数计算创建 Web 函数

5. 进入阿里云函数计算（参考官方帮助文档），创建一个 Web 函数：
   - CPU：0.1 核
   - 内存：128 MB（足够使用）
   - 在函数配置中添加如下环境变量，然后上传代码包，最后绑定对应域名。

| 变量名     | 值                                       |
| ---------- | ---------------------------------------- |
| kdocsToken | WPS 脚本令牌                             |
| kdocsUrl   | 表单脚本（获取限时练时间 hqsj）的 webhook |
| Secretkey  | 从 GoEasy 控制台获取的 Secret key        |

> 如果有备案域名，选择国内服务区；没有备案域名，选择中国香港区。

### 步骤 4：关联自动化流程与企微/钉钉机器人

6. 打开"呼叫考务表单"，创建副本；在自己的副本表单页面关联工作表；创建自动化流程，找到"钉钉群通知"或"企业微信群通知"，填入下一步生成的 webhook 地址。

7. 在企业微信群添加机器人，复制机器人生成的 webhook 地址，并填回上一步的表单自动化流程中。

### 步骤 5：修改前端按钮配置并部署

8. 复制"呼叫考务表单"地址。打开函数计算对应函数的代码开发页面，修改下列 JS 文件中的变量值。保存后，在编辑器的 Terminal 中执行：

```bash
npm install crypto
```

部署完成后，按照下方表格修改前端代码对应配置：

| 路径                    | 变量名 | 值                         |
| ----------------------- | ------ | -------------------------- |
| /code/public/js/button.js | 无     | 呼叫考务的表单地址         |
| /code/public/js/ms.js     | appkey | GoEasy 对应的 Client key   |

### 完成

保存并重新部署函数计算，即可在浏览器访问绑定的域名进入考务助手首页。
