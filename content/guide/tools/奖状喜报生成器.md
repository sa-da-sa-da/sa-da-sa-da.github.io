# 奖状 / 喜报生成器

奖状、喜报、表扬信三种版式，粘贴一份名单就能批量出，每张单独一页 A4 横向，直接送打印店。

## 直接访问

- 点击 [奖状喜报生成器](https://www.sakaay.com/lab/AI/jiangzhuang.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/jiangzhuang.html 并访问

## 核心功能

- **三种版式**：奖状、喜报、表扬信，各自独立记忆标题与正文模板
- **三套配色**：烫金红、宝蓝、墨绿，切换即时生效
- **纯 CSS 花边**：双层边框加 SVG 角花，不依赖外部图片，打印不失真
- **变量替换**：正文里写 `{姓名}`、`{奖项}`，生成时自动替换并高亮
- **批量生成**：名单每行一个名字，或「姓名,奖项」逐人指定奖项
- **逐张预览**：上一张 / 下一张翻看，确认没问题再打印
- **A4 横向打印**：每张独占一页，边距已排好
- **落款可改**：学校、班级、日期默认今天，随时调整
- **本地保存**：模板、名单、配色存在浏览器里
