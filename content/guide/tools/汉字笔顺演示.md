# 汉字笔顺演示

输入一个汉字，屏幕上按笔顺一笔一笔写出来。投到白板上讲生字，比老师在黑板上描十遍都清楚。

## 直接访问

- 点击 [汉字笔顺演示](https://www.sakaay.com/lab/AI/bishun.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/bishun.html 并访问

## 核心功能

- **按笔顺动画**：点播放，汉字按国家标准笔顺逐笔写出，可逐笔前进、重播、循环播放
- **速度可调**：慢 / 中 / 快三档，讲新字用慢速，复习时用快放
- **浅灰轮廓**：可开关轮廓显示，学生看得清每一笔该落在哪
- **田字格衬底**：画布后叠一层田字格，讲结构时更有参照
- **多字切换**：一次输入多个字，点字卡或按方向键切换
- **全屏投屏**：一键全屏，教室一体机上用
- **配套描红页**：同一页下方生成田字格描红纸（首字深色、其余浅灰），可打印
- **断网可用描红**：笔画数据加载失败时会提示，但描红打印不受影响
