# 听写播报器

把词表交给浏览器念。屏幕只显示进度不显示词语，学生没法偷看，老师也不用一遍遍重复。

## 直接访问

- 点击 [听写播报器](https://www.sakaay.com/lab/AI/tingxie.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/tingxie.html 并访问

## 核心功能

- **自动朗读**：调用浏览器语音合成，中文发音，无需联网接口
- **间隔可调**：每个词之间 3～15 秒滑块，留足书写时间
- **每词 1 / 2 / 3 遍**、语速 0.5～1.5 可调
- **屏幕不显示词语**：只显示「第 N 个 / 共 M 个」和倒计时圆环，防止学生偷看
- **完整控制**：开始、暂停、继续、停止、跳过当前、重读上一个
- **可选序号播报**：每个词前读「第 N 个」，默认关闭
- **结束提示音**：听写完成后播放叮咚提示
- **兼容提示**：浏览器不支持语音合成时明确提示改用 Chrome / Edge
- **词表本地保存**：自动剥离「1.」「（2）」「一、」等编号前缀
