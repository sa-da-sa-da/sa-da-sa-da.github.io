# 云朵字板贴生成器

输入一句话，生成圆润膨胀的云朵字板贴，打印出来剪下就能贴。黑板报、班级文化墙、活动布置都能用。

## 直接访问

- 点击 [云朵字板贴生成器](https://www.sakaay.com/lab/AI/yunduo.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/yunduo.html 并访问

## 核心功能

- **云朵字效果**：深色字芯配白色粗描边加柔和投影，形成膨胀圆润的板贴质感
- **按字或按词切分**：用空格分组，可以整句一起做，也可以一个字一个板贴
- **字号三档**：小 / 中 / 大，自动决定每页排几个
- **配色可选**：6 种填充色预设加自定义取色，描边可选白、浅黄、浅蓝
- **装饰角标**：星星、爱心、笑脸三种小装饰，可关掉
- **裁剪虚线框**：每个板贴带圆角虚线框，沿框剪下即可
- **A4 打印**：超出自动分页，只打印板贴内容
- **本地保存**：文字与配色存在浏览器里
