# 背诵检查大屏

导入名单，投屏到教室电视，点一下名字就变绿。谁背了谁没背，全班看得见。

## 直接访问

- 点击 [背诵检查大屏](https://www.sakaay.com/lab/AI/beisong.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/beisong.html 并访问

## 核心功能

- **三态切换**：点一次「已背诵」（绿）、再点一次「需重背」（红）、再点回到未检查（灰）
- **实时统计**：顶部显示已背 / 需重背 / 未检查人数，配已背比例进度条
- **筛选视图**：全部、未检查、已背、需重背四个标签，还能按小组筛
- **分组支持**：名单按「姓名,组名」格式录入，可分组管理
- **随机抽人**：一键抽一个还没检查的学生，卡片高亮闪烁两秒
- **切换次数**：每张卡片记录被点了几次，反复检查的学生一眼看出来
- **深色大屏配色**：字号大、对比强，投影后后排也看得清
- **本地保存**：名单与状态存在浏览器里
