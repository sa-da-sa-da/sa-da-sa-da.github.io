# 课堂打卡单

给每个学生配一个动物头像，点一下卡片就飞到「已打卡」区。低年级课堂点名、任务完成、活动签到都能用。

## 直接访问

- 点击 [课堂打卡单](https://www.sakaay.com/lab/AI/daka.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/daka.html 并访问

## 核心功能

- **动物头像自动分配**：16 种动物表情按名字固定分配，同一学生每次打开头像都一样
- **点一下即打卡**：卡片变绿打勾并移到下方已打卡区，再点可撤销
- **进度一目了然**：顶部进度条与「已完成 X / 共 Y」实时更新
- **全员完成庆祝**：所有人打完卡自动弹出礼花庆祝层
- **批量操作**：一键全部完成、一键重置、打乱顺序
- **名单随时改**：内置名单编辑区，改完自动保存
- **大卡片设计**：圆角、鲜艳、字号大，适合手机和平板操作
- **本地保存**：名单、完成状态与头像映射都存在浏览器里
