# 闪卡 / 单词卡生成器

一边在网页上翻卡背诵，一边能打印成实体卡片。每行写「正面,背面」，单词、古诗名句、公式释义都能做。

## 直接访问

- 点击 [闪卡单词卡生成器](https://www.sakaay.com/lab/AI/shanka.html)
- 地址栏输入：https://www.sakaay.com/lab/AI/shanka.html 并访问

## 核心功能

- **一行一张卡**：正面与背面用逗号、Tab、竖线或两个以上空格分隔都能识别
- **3D 翻卡**：点卡片或按空格翻面，← → 切换上一张下一张
- **洗牌**：一键打乱顺序，避免每次按同样次序背
- **掌握标记**：每张可标「已掌握 / 再练练」，顶部进度条显示掌握比例
- **只看没掌握的**：勾选后自动跳过已掌握卡片，适合考前冲刺
- **多卡组保存**：给卡组起名保存到浏览器，下次从下拉框直接载入
- **对折打印**：A4 两列，左列正面右列背面，沿中缝对折后裁开即可，每页最多 7 行
