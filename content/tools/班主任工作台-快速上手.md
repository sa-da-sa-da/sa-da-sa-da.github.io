# 班主任工作台 · 快速上手

一个**纯浏览器里运行**的班级管理工具:不用装软件、不用注册账号、不用联网。

- 在线地址:<https://www.sakaay.com/class-workbench.html>
- 数据全部存在**你自己浏览器的本地存储**里,不上传任何服务器

---

## ⚠️ 先记住这一条

**数据只在这台电脑的这个浏览器里。**

换电脑、换浏览器、清理浏览器数据、用无痕模式 —— 数据都会消失。

所以:**顶栏的「💾 备份」要定期点**,把导出的 JSON 文件存到网盘或 U 盘。

---

## 5 分钟上手

| 步骤 | 操作 |
| --- | --- |
| 1. 建班级 | 顶栏「🏫」右侧的「⚙」→ 新建班级(如 `初二(1)班`)。多个班级数据完全独立 |
| 2. 录花名册 | 左侧「学生档案库 → 全班花名册」→「📥 批量添加」用 Excel 导入最快(可先「⬇ 模板」下载空表) |
| 3. 排座位 | 「座位表」页直接内嵌排座工具,自动读取花名册;排完的结果会写回工作台 |
| 4. 记成绩 | 「智能成绩分析 → 考试批次管理」先建批次(周测/月考/期末),再录分数 |
| 5. 日常用 | 首页仪表盘一眼看到:本周待办、待沟通家长、重点学生、材料倒计时 |

> **花名册是所有学生数据的源头**。其他模块(成绩、心理、住宿、考勤…)里的学生都只能从花名册里选,不能手打,这样能保证姓名不会写错、不会重复。

## 常用操作速查

| 想做什么 | 怎么点 |
| --- | --- |
| 加一条记录 | 表格右上角「＋ 新增」 |
| 批量导入 | 「📥 批量添加」→ 选 Excel / CSV(建议先「⬇ 模板」) |
| 导出表格 | 「⬇ 导出」 |
| 找记录 | 搜索框(全字段模糊)+ 分类下拉 + 日期范围 + 标签点选 |
| 批量删除 | 勾左侧复选框 → 底部「🗑 批量删除」 |
| 给学生打标签 | 花名册的「学生标签」字段,按分组点选,也可以自己加 |
| 待办转档案 | 待办条目点「📦」可归档到任意模块,归档去向可追溯 |

## 多班级

- 顶栏「🏫」下拉直接切换班级
- 点「⚙」可以新建 / 重命名 / 删除班级

**每个班的花名册、成绩、课程表、待办、快照都是完全独立的**,互不影响。
删除班级会清空该班全部数据,且**不可恢复**(会二次确认)。

---

## 备份 / 恢复 / 版本快照

| 功能 | 说明 |
| --- | --- |
| **💾 备份** | 导出一个 JSON,包含全部班级数据 **+ 座位表排座结果** |
| **♻ 恢复** | 选备份文件导入,会**覆盖**当前全部数据(导入前会确认) |
| **📦 版本** | 手动存快照;系统每 10 分钟自动存一次,最多保留 60 个,可随时回滚 |

> ⚠️ **版本快照里不包含座位表**。座位表数据只能通过「💾 备份」导出保存。

## 🙈 隐私打码(截图专用)

顶栏「🙈 隐私」点一下,所有**人名、学号、电话、住址、家长信息、科目**都会变成 `***`,可以放心截图;再点一次恢复。

覆盖范围:

- 花名册、家长通讯录、心理/医务/特殊学生等所有表格
- 成绩分析、宿舍、值日、仪表盘
- 课程表、任课表、教师个人课表
- 座位表(内嵌工具会同步打码)

开关**会被记住**,刷新页面仍然是隐藏状态。

> 注意:它只遮挡**屏幕上的显示**。备份文件和导出的 Excel 里仍然是真实信息。

## 常见问题

**换电脑了怎么办?**
老电脑点「💾 备份」拿到 JSON 文件 → 新电脑打开工作台点「♻ 恢复」导入。

**Excel 导入没反应 / 数据错位?**
只支持 `.xlsx / .xls / .csv`;列名尽量和模板一致,不确定的列可以留空后手动补。

**数据会上传到网上吗?**
不会,纯本地运行。但也正因如此,清缓存 = 数据没了。

**座位表打不开 / 一片空白?**
点座位表页右上角的「↻ 刷新花名册」,重新同步一次花名册。

**能几个人一起用吗?**
目前是单机版,数据不共享。多人协作需要各自维护,或用「备份 / 恢复」手工同步。
